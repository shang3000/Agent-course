# 三个附加单元路线

## Bonus 1：函数调用微调

适合已经理解工具调用、聊天模板和监督微调后学习。重点是训练样本格式、工具 schema、LoRA 和结构化调用评测。训练格式必须与推理模板一致。

## Bonus 2：可观测性与评估

把一次 Agent 任务记录为 Trace，把模型、检索和工具调用记录为 Spans。在线关注成功率、延迟、成本和安全；离线用固定数据集做版本回归。敏感数据进入追踪平台前应脱敏。

## Bonus 3：宝可梦 Agent

通过 poke-env 与 Pokémon Showdown 获取环境状态和合法行动。Agent 必须从合法招式/换人中选择，并用多局胜率、非法动作率和回合长度评估策略。

推荐顺序：完成 Unit 1—3 → 可观测性 → 函数调用微调或游戏 Agent。
