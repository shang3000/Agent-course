# Unit 4：GAIA 最终项目

## GAIA 在测什么

GAIA 题目常需要组合网页检索、文件处理、计算、多模态理解和多步推理。难点不只是“模型聪明”，而是 Agent 能否稳定使用正确工具并提交格式准确的答案。

## 推荐开发流程

1. 建立最小 Agent 基线。
2. 保存每题完整轨迹和最终答案。
3. 把失败分类为检索、工具、规划、解析、格式或超时。
4. 一次只修改一个变量。
5. 在固定题集重新评估，防止回归。

## 最终答案规范

很多评测使用严格匹配。应统一处理：

- 多余解释和前后缀；
- 数字、百分比和单位；
- 日期与时区；
- 人名、地名和大小写；
- 列表排序和分隔符。
