# Unit 1.1：什么是智能体？

课程原页：[什么是智能体？](https://huggingface.co/learn/agents-course/zh-CN/unit1/what-are-agents)

## 一句话先记住

**Agent = 会规划的模型 + 能行动的工具 + 根据结果继续调整的循环。**

## 用“出门是否带伞”理解

只有 LLM 时，它只能根据已有文字知识生成建议。它不知道今天真实的天气，可能只会说“建议查看天气预报”。

Agent 会经历下面的过程：

1. Thought：要回答是否带伞，我缺少实时天气。
2. Action：调用天气工具。
3. Observation：工具返回“18℃，小雨”。
4. Thought：信息已经足够，可以形成答案。
5. Final Answer：建议带伞。

## 四个关键零件

| 零件 | 作用 | 带伞例子 |
| --- | --- | --- |
| 目标 | 告诉系统最终要完成什么 | 判断是否需要带伞 |
| 模型 | 理解、推理、规划和选择工具 | 判断需要查询实时天气 |
| 工具 | 真正获取信息或改变环境 | 调用天气 API |
| 循环 | 把结果送回模型并决定是否继续 | 根据天气结果形成答案 |

## 最容易误会的地方

LLM 通常只负责生成文本，它自己并没有真的执行 Python 函数。Agent 框架会解析模型生成的工具调用请求，执行相应函数，再把函数结果作为 Observation 交还给模型。

Action 和 Tool 也不是完全相同的概念：Action 是“要做的事”，一个 Action 可能使用一个或多个 Tool。
