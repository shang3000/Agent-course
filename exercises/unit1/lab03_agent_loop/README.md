# 实验 03：最小 Agent 循环

## 目标

亲手连接“模型决策 → Action → 工具执行 → Observation → 下一轮决策”，并设置最大步数终止条件。

## 任务

完成 `starter.py` 中的 `run_agent()`：

1. 把用户问题写入消息历史。
2. 每轮调用决策模型。
3. 遇到 `tool` 决策时调用受控执行器。
4. 把真实执行结果作为 Observation 追加到历史。
5. 遇到 `final` 返回答案；超过最大步数则明确失败。

这里使用 `ScriptedModel` 代替真实 LLM，因此完全离线。它不是“假装已经调用了 AI”，而是为了让循环的数据流可重复测试。

## 预期输出

```text
建议带伞；依据：大连教学模拟天气为 18℃ 且有雨。
```

## 常见错误

- 让模型自己生成 Observation，而不执行工具。
- 工具失败后仍当作成功数据继续。
- 没有最大步数，错误策略可能无限循环。
- 只保留最终答案，不记录 Action 与 Observation，导致无法调试。

## 失败练习

让模型请求 `unknown_tool`，观察错误如何进入下一轮；再让模型永远请求工具，确认 `max_steps` 能终止循环。
