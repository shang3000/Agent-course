# 实验 02：工具 schema 与执行器

## 目标

让模型只能提出“调用意图”，由受控执行器验证工具名称和参数后运行真正的 Python 函数。

## 任务

完成 `starter.py` 中的 `execute_tool()`：

1. 拒绝未知工具。
2. 拒绝缺失参数。
3. 拒绝错误参数类型。
4. 参数通过后才执行函数。
5. 用结构化结果区分成功和失败。

## 预期输出

```text
{'ok': True, 'tool': 'get_weather', 'data': {'city': '大连', 'temperature': 18, 'rain': True}}
```

## 常见错误

- 直接执行模型生成的任意函数名。
- 只检查 JSON 语法，不检查参数类型。
- 把异常堆栈原样交给用户或模型。
- 工具描述写“查东西”，没有输入、输出和适用边界。

## 失败练习

分别传入 `unknown_tool`、缺失 `city`、以及 `city=123`，确认三种失败都不会调用天气函数。
