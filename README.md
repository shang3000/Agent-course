# Hugging Face Agents Course 伴读项目

这个项目用于配合 [Hugging Face Agents Course 中文课程](https://huggingface.co/learn/agents-course/zh-CN) 学习。

## 当前内容

- `learning-site/`：交互式中文伴读网页
- `notes/`：可搜索、可长期保存的逐课批注
- `exercises/`：与课程概念对应的最小 Python 实验
- 根目录原有的 Python 文件：早期自由实验，暂不作为伴读项目的正式内容
